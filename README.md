# OTIUM Curadoria

Landing page editorial da **OTIUM**, criada para apresentar a curadoria multimarcas da loja.

## Estrutura
- Página estática em `index.html`
- Responsiva para desktop e mobile
- Preparada para deploy na Vercel
- Links de retorno para a loja Nuvemshop

## Deploy
O projeto pode ser importado diretamente na Vercel a partir deste repositório.
